# wx_channel v5.7.8

发布日期：2026-08-29

## 版本摘要

v5.7.8 将公众号文章采集、目录管理、互动指标和本地归档接入现有 wx_channel API 与下载流程，同时继续加固视频号页面客户端和管理控制台入口。

## 公众号资料库

- 打开已登录微信中的公众号文章或主页后，自动捕获账号元数据和短期会话，按 `biz` 去重并保存到本机。
- 支持公众号名称或 `biz` 搜索、分页账号列表、文章目录、文章筛选、归档状态和同步状态查看。
- 支持同步最近一页或全部历史文章；同步游标、运行状态和错误信息按页保存，可中断后继续、取消并避免重复入库。
- 通过现有下载链路保存文章 HTML、图片等资源，生成本地 manifest 和资源清单，支持归档复用与失败重试。

## 互动指标与数据迁移

- 支持采集并追加保存阅读、点赞、评论、转发、收藏和赞赏指标快照。
- 指标状态区分成功、未返回和失败，明确区分上游的 `0` 与缺失字段；支持待采集指标、全部刷新、逐篇落库、断点续跑和幂等保护。
- 支持公众号目录 JSON/ZIP 导入导出、导入预检和冲突策略，覆盖账号、文章、资源、归档状态、指标快照和同步状态。
- 导出文件不包含短期凭证；文章归档文件仍按本机路径管理，导入后需要重新建立有效页面会话。

## 视频号与管理控制台

- 公众号页面底部菜单和视频号首页新增“管理控制台”入口，使用独立控制台图标，与下载入口分开。
- 加固视频号页面 API 客户端的连接超时、心跳失败、旧连接事件和页面卸载处理，降低首次请求失败和断线后无法恢复的问题。
- 保留本地控制台、视频号页面和公众号页面所需的明确来源白名单，确保注入脚本和本地 API 调度可用。

## 使用前提

公众号账号捕获、历史文章和互动指标获取需要本机已登录的微信桌面端打开对应公众号页面。仅凭公众号名称或 `biz` 不能绕过微信会话获取完整历史和互动数据。
