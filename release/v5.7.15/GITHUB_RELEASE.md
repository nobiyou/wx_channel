# wx_channel v5.7.15

发布日期：2026-11-10

## 视频号 MCP 与视频分析

- 集成 wx_channel MCP，可在agent中查询本地浏览/下载记录，以及微信页面就绪时的账号、视频、详情、评论和分享链接数据。
- 新增账号搜索、分页、运行时状态和稳定错误契约，明确区分实时数据、历史数据、缺失字段和页面未就绪。
- 增加下载优先的视频内容分析流程，支持本地媒体探测、抽帧、画面拆解、语音/字幕证据、分镜脚本和 JSON/HTML 报告。
- 提供 `wechat-channel-insight` 与 `wechat-channel-video-analysis` 两个独立 Skill，分别负责数据查询和视频复盘工作流。
