# wx_channel v5.7.15

发布日期：2026-11-10

## Codex 视频号 MCP 与视频分析

- 集成 wx_channel MCP，可在 Codex 中查询本地浏览/下载记录，以及微信页面就绪时的账号、视频、详情、评论和分享链接数据。
- 新增账号搜索、分页、运行时状态和稳定错误契约，明确区分实时数据、历史数据、缺失字段和页面未就绪。
- 增加下载优先的视频内容分析流程，支持本地媒体探测、抽帧、画面拆解、语音/字幕证据、分镜脚本和 JSON/HTML 报告。
- 提供 `wechat-channel-insight` 与 `wechat-channel-video-analysis` 两个独立 Skill，分别负责数据查询和视频复盘工作流。

## 互动指标契约调整

- 播放量从 MCP 公共契约移除，不输出空的 `play_count`，不把缺失值补成 0，也不因缺失播放量删除视频记录。
- 新指标快照不再写入播放量；旧快照中的 `play_count` 兼容读取时忽略，点赞、评论、收藏和转发继续保留来源与缺失状态。
