# wx_channel v5.7.9

发布日期：2026-09-01

## 版本摘要

v5.7.9 聚焦长时间运行稳定性、视频号页面恢复和长标题下载文件名，同时修复公众号推送列表首次请求的凭证竞态。

## 长时间运行与视频号页面恢复

- 增加应用层功能健康探测：连接建立后延迟探测，之后定期确认微信页面 API 仍可实际响应。
- 心跳等待服务端确认，连续失败时自动重连；服务端区分应用层活跃、协议层活跃和 API 功能状态。
- 修复 WebSocket 读取被固定空闲超时误断开的问题。
- 协议连接仍存活但页面脚本失活时，自动通过 Windows 页面打开器重新激活视频号页面。
- 保留旧连接事件保护、页面卸载处理、请求中的探测避让和健康状态上报。

## 视频号页面自动检查配置

- 新增 `auto_open_channels` 配置项。
- 标准版和 Radar 版默认关闭，Cloud 版默认开启；用户仍可在 `config.yaml` 中覆盖。

## 长标题下载文件名

- 移除固定 50 字符限制，按目标目录、文件名和扩展名动态计算 Windows UTF-16 路径预算。
- 标题主体最多使用 180 个 UTF-16 单元，视频 ID、画质/分辨率后缀和扩展名优先保留。
- 批量、队列、分片合并、页面直连和历史任务恢复统一使用新命名规则；重名序号也会重新计算路径长度。
- 数据库和下载记录继续保存完整原始标题，文件名只是落盘时的安全投影。

## 公众号请求稳定性

- 推送列表打开前等待公众号凭证刷新完成，降低首次 `/api/mp/msg/list` 返回 401 的概率。
- 后台账号同步复用进行中的 Promise，避免后台刷新与前台列表读取互相竞争。

## 发布资产

- `wx_channel_v5.7.9.zip`：标准版，不主动打开视频号页面。
- `wx_channel_cloud_v5.7.9.zip`：Cloud 版，默认打开并检查视频号页面。
- `wx_channel_radar_v5.7.9.zip`：Radar 版，默认不主动打开视频号页面。

每个 ZIP 包含对应 EXE、`README.md`、配置样例和 Web 控制台资源。
