# wx_channel v5.7.14

发布日期：2026-11-05

## 下载目录安全修复

- 修复 Windows 下载目录内 Junction 或符号链接指向目录外时可能读取外部文件的问题。
- 使用 Windows 文件句柄解析实际路径，支持合法内部跳转、根目录别名、长路径和 UNC 路径。
- 解析失败直接拒绝访问，越界请求返回 HTTP 403。
- 视频流使用受限文件句柄，保持完整视频和 Range 播放。
- 修复非 Windows 下符号链接与 `..` 组合造成的路径校验不一致。
