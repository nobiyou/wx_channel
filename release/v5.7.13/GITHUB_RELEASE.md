# wx_channel v5.7.13

发布日期：2026-10-15

## 个人主页视频与直播回放分栏

- 个人主页批量下载弹窗提供“视频”和“直播回放”两个标签，默认显示视频，避免下载短视频时混入回放（[#113](https://github.com/nobiyou/wx_channel/issues/113)）。
- 分页、全选、已选数量、下载、导出和清空只作用于当前分类；切换标签保留各自勾选，不会下载隐藏分类的条目。
- 下载期间暂时锁定分类切换；关闭再打开弹窗保留分类、勾选、页码和进度，并补入隐藏期间新采集的内容。
- 增加分类空态、键盘操作和小屏宽度适配，全选跳过不可下载的条目。

## 稳定性与自动化验证

- 日志目录或文件不可写时继续输出控制台日志，避免空指针崩溃，并显示文件日志不可用的具体原因。
- CI 使用 `go.mod` 指定的 Go 版本，补齐 Windows/Linux 构建、Go 测试和 JavaScript 测试。
- 补齐 SunnyNet 内嵌所需的两份 NFAPI DLL 源码资源，修复干净检出缺失资源的构建失败。
- 统一 CI 与打包的 SQLite 构建选项，升级 SQLite 适配器至 v0.2.0，修复重复链接及新 Windows 编译器兼容问题。

## 下载说明

- Windows 64 位提供标准版、云端版和雷达版，每个版本均提供 EXE 和 ZIP。
- 首次使用建议下载 ZIP 并完整解压；升级时保留原有配置和下载数据。
- 列表显示已采集的内容；需要先在微信个人主页打开相应列表加载视频或直播回放。
