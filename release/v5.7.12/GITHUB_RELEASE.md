# wx_channel v5.7.12

发布日期：2026-10-10

## 视频下载签名与画质选择修复

- 后端切换画质仅替换或追加 `X-snsvideoflag`，保留微信 CDN 其他签名参数的原始顺序与编码，修复 HTTP 400 下载失败。
- 单个与批量下载优先使用微信明确返回的 `fullUrl` 原始地址；未提供时自动选择最高可用 `spec` 画质。
- 规格选择按码率优先，码率缺失时沿用微信返回顺序，不再硬编码优先 `xWT111`。
- 单个下载遇到 Gopeed Range 探测返回 HTTP 400 时回退到后端单流下载，保留来源请求头、进度和落盘处理。
- 下载菜单明确区分原始视频与最高可用画质，原始模式继续强制单连接并保留源文件大小校验。

## 使用说明

“微信当前未返回原始流”表示当前视频数据没有提供明确原始地址；此时单个与批量下载均选择最高可用规格。最高可用画质不代表上传前的原始视频。
