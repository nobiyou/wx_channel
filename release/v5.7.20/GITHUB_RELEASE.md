# wx_channel v5.7.20

修复 v5.7.19 中个人主页批量下载提示「暂无视频数据」的问题，恢复终端中的操作和结果日志。

## 主要更新

- **个人主页批量下载**：修复视频列表未采集的问题，包括未打开直播页的情况。保留视频与直播回放分栏、分页、勾选和弹窗重开状态。
- **页面识别**：页面脚本传递当前页面上下文，避免跨域脚本仅提供域名 Referer 时误识别为登录页；继续隔离登录页和直播页脚本及缓存。
- **操作日志**：恢复下载开始、已启动、跳过、取消、下载模式与文件名提示。
- **结果日志**：恢复带视频标题的单视频完成和失败通知，失败使用错误级别；批量下载逐个显示开始、完成及最终成功/失败汇总。
- **其他提示**：恢复封面保存、评论导出任务创建、喜欢/收藏数据加载和页面模块切换日志。高频进度和完整视频链接继续写入文件日志。

## 下载包

- `wx_channel_v5.7.20.zip`：标准版。
- `wx_channel_cloud_v5.7.20.zip`：Cloud 版。
- `wx_channel_radar_v5.7.20.zip`：Radar 版。
- `wx_channel_video_analysis_v5.7.20.zip`：标准版及 FFmpeg 视频分析工具。
- `wx-channel-environment.zip`：独立 Windows 环境检查与修复工具，适用于 Windows 10/11。
- `SHA256SUMS.txt`：上述五个 ZIP 文件的 SHA-256 校验值。

## 升级与验证

- 退出旧程序，解压并启动新版本，再重新打开视频号页面，使页面加载最新脚本。
- 全量 Go 测试与 108 项 JavaScript 测试通过；个人主页批量下载及操作/结果日志恢复已完成人工核验。
- 三个 Windows 主程序的内嵌版本与文件版本均为 `5.7.20`，ZIP 内主程序与对应独立 EXE 的 SHA-256 一致。
- 发布包包含三类 Agent 的 MCP 配置模板与工作流 Skill，不包含运行时日志、下载记录、私有配置、MCP Token 或硬件身份文件。
