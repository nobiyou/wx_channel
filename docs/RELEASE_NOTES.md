## 最新版本：v5.7.5（2026-08-26）

### 重点更新

- 修复微信 CDN 原始流规则变化导致转码文件被误标为原始视频的问题。
- 仅当微信明确返回 `fullUrl` 时标记原始视频；仅有源文件大小提示时不再冒充原始流。
- 未返回原始流时默认选择最高可用画质（当前优先 `xWT111`），界面明确显示实际下载模式。
- 页面直连失败自动回退后端，并保留完整签名 URL、Referer、Origin 和用户代理。
- 增加下载大小校验，拦截明显低于源文件提示的低码率流。

### 运行兼容

- v5.7.4 的视频号生命周期管理、Cloud/Insight Edge 配置和已有下载记录继续兼容。
