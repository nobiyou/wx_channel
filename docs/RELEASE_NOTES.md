# 版本更新说明

## 当前版本

- 版本号：`v5.7.9`
- 代码版本常量：`internal/version/version.go`
- 最新文档整理时间：`2026-09-01`

## 最新版本：v5.7.9（2026-09-01）

### 长时间运行与视频号页面恢复

- 增加页面应用层健康探测、心跳确认和断线重连，区分协议连接存活与页面 API 是否仍可用。
- 修复 WebSocket 固定读取超时造成的误断开；页面脚本失活时自动通过 Windows 页面打开器恢复视频号页面。
- `/api/channels/status` 继续提供应用层、协议层和 API 功能状态，便于判断程序是否真正可调度。

### 自动打开策略与长标题文件名

- 新增 `auto_open_channels` 配置项：标准版和 Radar 版默认关闭，Cloud 版默认开启。
- 下载标题不再固定截断到 50 字符，按目标目录动态计算 Windows UTF-16 路径预算，保留视频 ID、画质后缀和扩展名。
- 批量、队列、分片和页面直连下载统一使用新的安全命名与重名规则，数据库仍保存完整原始标题。

### 公众号请求稳定性

- 推送列表读取前等待公众号凭证刷新完成，修复首次 `/api/mp/msg/list` 请求可能返回 401 的竞态。

## 上一发布版本：v5.7.8（2026-08-29）

公众号资料库、历史文章同步、文章归档、互动指标和管理控制台入口，详见下方记录。

<!-- v5.7.8 details retained below for historical reference. -->

### 公众号资料库与历史文章管理

- 打开已登录微信中的公众号文章或主页后，自动捕获账号元数据和短期会话，按 `biz` 去重并保存到本机目录。
- 新增公众号名称/`biz` 搜索、分页账号列表、文章目录和同步状态展示。
- 支持最近一页或全部历史文章同步，按页保存游标，支持断点续跑、取消和重复同步去重。
- 支持文章 HTML、图片等资源经现有下载链路归档，保存 manifest、资源状态和归档结果。

### 互动指标与迁移

- 保存阅读、点赞、评论、转发、收藏、赞赏互动快照，区分明确的 `0` 与上游未返回值。
- “采集待采集指标”和“刷新全部指标”均支持逐篇落库、断点续跑、有限重试、取消和幂等保护。
- 支持目录 JSON/ZIP 导入导出、导入预检和冲突策略；导出文件不含短期凭证，归档文件仍由本机路径管理。

### 控制台与视频号稳定性

- 新增公众号资料库控制台页面，提供账号卡片、文章筛选、归档状态、指标状态和同步进度。
- 公众号页面和视频号首页新增“管理控制台”入口，控制台图标与下载图标分离。
- 加固视频号页面 API 客户端的连接超时、心跳失败、旧连接事件和页面卸载处理，并补充明确来源白名单。

### 使用前提

- 公众号账号捕获、历史文章和互动指标获取仍需在本机已登录的微信桌面端打开对应公众号页面；仅凭公众号名称或 `biz` 不能绕过微信会话获取完整数据。
- 公众号目录导出不包含短期凭证；导入后仍需在本机重新建立有效页面会话。

## 上一发布版本：v5.7.7（2026-08-26）

### 批量下载画质回退修复

- 修复批量下载在缺少真实原始 `fullUrl` 时仍按原始模式下载，导致所有任务被低码率大小校验拒绝的问题。
- 批量下载与单个下载共用最高可用画质回退规则，并保留完整签名 CDN 地址。
- 保留低码率保护，新增截图中 `4.26 MB -> 0.25 MB` 的回归测试。

## 上一发布版本：v5.7.6（2026-08-26）

### 重点更新

- 修复 Cloud/Insight Edge WebSocket 心跳 ACK，避免长时间无业务消息时误报 `context deadline exceeded` 并断线重连。
- 增加连接活跃度与 `last_pong_at` 状态，过期客户端不参与搜索、列表和分享解析调度。
- 分享链接解析支持严格地址校验、批量并发、重复 URL 去重、超时控制和结构化错误码。
- `/api/channels/status` 增加页面/分享平台状态数量、fresh 客户端数量和可调度客户端数量。

### 运行兼容

- v5.7.5 的下载链路保护、视频号生命周期管理、Cloud/Insight Edge 配置和已有下载记录继续兼容。
